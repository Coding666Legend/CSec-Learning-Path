# Linux Privilege Escalation
#### Lab Environment
The following THM lab will be used for the Hands-on of Linux Privilege Escalation:
link - https://tryhackme.com/room/linuxprivescarena

**Steps to Connect to machine:**
1. Navigate to link. Start Lab Machine. Wait ~5mins for the Machine to fully boot-up
2. Connect to THM server via Openvpn and .ovpn file
3. ssh to machine
```bash
ssh -o HostKeyAlgorithms=+ssh-rsa TCM@<machine-ip>

#username: TCM  
#password: Hacker123
```
4. Successfully Connected To The Machine....
